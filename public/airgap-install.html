Install JEE Airgap Shield

Airgap Shield is available on the Chrome Web Store — install it in seconds, no developer mode needed.

  1. Click "Add to Chrome" below — it opens the Chrome Web Store.
  2. Click Add to Chrome on the store page and confirm.
  3. Return here and refresh the dashboard.
  1. Click "Add to Firefox" below — it opens the Firefox Add-ons store.
  2. Click Add to Firefox on the store page and confirm.
  3. Return here and refresh the dashboard.
