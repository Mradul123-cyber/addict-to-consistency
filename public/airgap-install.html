Install JEE Airgap Shield

The Airgap toggle works through the Chrome extension in this repo. Load the extension once, then refresh the dashboard tab.

  1. Click "Download Extension (.zip)" above, unzip it — you'll get a single extension folder ready to load.
  2. Click "Open chrome://extensions" above — or type it manually in your address bar.
  3. Toggle Developer mode ON (top-right switch on that page).
  4. Click Load unpacked → navigate into the unzipped folder → open the extension subfolder inside it.
  5. Return here and refresh — the Airgap Shield will activate automatically.

Only works on Chrome or Chromium-based browsers (Brave, Edge). Not supported on Firefox or Safari.
