Install JEE Airgap Shield

The Airgap toggle works through the Chrome extension in this repo. Load the extension once, then refresh the dashboard tab.

  1. Download or clone the repository locally.
  2. Open chrome://extensions in Chrome.
  3. Enable Developer mode.
  4. Click Load unpacked and select the repo's extension/ folder.
  5. Return to JEE Workstation and refresh the app tab.
