Install JEE Airgap Shield

Load the extension once, then refresh the dashboard tab. Extensions are loaded temporarily and last until you close the browser.

  1. Click "Download Extension (.zip)" below, unzip it.
  2. Open chrome://extensions in your address bar.
  3. Toggle Developer mode ON (top-right).
  4. Click Load unpacked → select the extension folder.
  5. Return here and refresh the dashboard.
  1. Click "Download Extension (.zip)" below, unzip it.
  2. Open about:debugging#/runtime/this-firefox in your address bar.
  3. Click Load Temporary Add-on → navigate into the extension/firefox folder → select any file.
  4. Return here and refresh the dashboard.

Temporary add-ons last only until Firefox is closed. For permanent installation, submit to the Firefox Add-ons store.
